# líquida — publicar no GitHub Pages

1. Crie um repositório público no GitHub (ex.: `liquida`).
2. Clique em **Add file → Upload files** e envie TODOS os arquivos desta pasta (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, notif-icon.png).
3. Vá em **Settings → Pages**, em *Branch* escolha `main` e pasta `/ (root)`, salve.
4. Em ~1 minuto o site fica em: `https://SEU-USUARIO.github.io/liquida/`

## Notificações no celular
- **Android (Chrome):** abra o link, toque no sino 🔔 → Ativar → Permitir.
- **iPhone (iOS 16.4+):** abra no Safari → Compartilhar → *Adicionar à Tela de Início*. Abra pelo ícone, toque no sino → Ativar → Permitir.
- No sino você configura valor, tempo até aprovar e intervalo entre vendas.
- As notificações chegam enquanto o app estiver aberto (inclusive em segundo plano). Com o app totalmente fechado seria necessário um servidor de push.
